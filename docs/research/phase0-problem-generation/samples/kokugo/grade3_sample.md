# 国語 3年生サンプル問題セット(領域: 漢字・文法)

生成条件: `kokugo-prompt.md` のテンプレートに grade=3, domain=漢字・文法(主語述語・修飾語) を適用して生成。

---

### 問題1(基礎)
次の文の「主語」と「述語」をそれぞれ書きぬきましょう。

「弟は 大きな こえで 歌った。」

- 解答: 主語=弟は / 述語=歌った
- 解説: 「だれが」にあたる部分が主語、「どうする」にあたる部分が述語。
- 対応項目: 〔知識及び技能〕(1)カ 主語と述語との関係

### 問題2(標準)
次の文の「──」が修飾している言葉(くわしくしている言葉)を選びましょう。

「あかい 花が さいた。」
ア. 花が　イ. さいた

- 解答: ア(花が)
- 解説: 「あかい」は花の様子をくわしくしている修飾語なので、修飾される言葉は「花が」。
- 対応項目: 〔知識及び技能〕(1)カ 修飾と被修飾との関係

### 問題3(標準)
次の漢字の読み方をひらがなで書きましょう。
「学級」「昭和」「宮殿」

- 解答: がっきゅう / しょうわ / きゅうでん
- 解説: いずれも3年生までの学年別漢字配当表に含まれる漢字。
- 対応項目: 〔知識及び技能〕(1)エ 漢字の読み

### 問題4(応用)
次の文を、主語と述語がそれぞれ1つずつになるように、2つの文に分けて書きましょう。

「妹は 絵をかき、兄は それを 見て わらった。」

- 解答例: 「妹は絵をかいた。」「兄はそれを見てわらった。」
- 解説: 元の文は主語述語のペアが2組ある「重文」。3年生では重文の構造理解までは求められないため、
  「主語と述語が対応していることに注目して文を分ける」という具体的操作に落とし込んだ。
- 対応項目: 〔知識及び技能〕(1)カ 主語と述語との関係(応用)
