# 国語 5年生サンプル問題セット(領域: 敬語・読解)

生成条件: `kokugo-prompt.md` のテンプレートに grade=5, domain=敬語・読解 を適用して生成。

---

### 問題1(基礎)
次の言葉を、尊敬語・謙譲語・丁寧語のどれかに分類しましょう。

「いらっしゃる」「申す」「です」

- 解答: いらっしゃる=尊敬語 / 申す=謙譲語 / です=丁寧語
- 解説: 相手を高める表現が尊敬語、自分をへりくだる表現が謙譲語、丁寧に言う表現が丁寧語。
- 対応項目: 〔知識及び技能〕(1)ク 敬語の使い方

### 問題2(標準)
次の文を、正しい敬語に直しましょう。

「先生が わたしの家に 来た。」

- 解答: 「先生が わたしの家に いらっしゃった(お越しになった)。」
- 解説: 相手(先生)の動作には尊敬語を使う。
- 対応項目: 〔知識及び技能〕(1)ク 敬語の使い方(適切な運用)

### 問題3(標準・読解)
次の文章を読んで、あとの問いに答えましょう。

「たけしは、大会前日、いつもより早く布団に入った。しかし目はさえて、何度も寝返りを打った。明日のリレーのことを考えると、胸の奥がざわついた。」

問: たけしの気持ちとして最も適切なものを選びましょう。
ア. 大会が楽しみでわくわくしている
イ. 大会への不安や緊張を感じている
ウ. 大会に興味がなく退屈している

- 解答: イ
- 解説: 「目がさえて何度も寝返りを打つ」「胸の奥がざわつく」という行動・身体描写から、不安・緊張の心情を読み取る。
- 対応項目: C(1) 精査・解釈(心情を表す描写の読み取り)

### 問題4(応用・読解)
問題3の文章の続きとして、「たけしが不安を乗りこえて練習の成果を発揮する」という展開にするには、
どのような一文を入れるとよいか、25字以内で書きましょう。

- 解答例: 「けれど、毎日重ねた練習を思い出し、少しずつ心が落ち着いていった。」(29字程度、字数は解答例のため許容範囲で評価)
- 解説: 心情の転換点となる一文を、これまでの描写(不安)と対比させながら自分の言葉で構成する記述式問題。
- 対応項目: C(1) 考えの形成/記述による表現
- 難易度メモ: 記述式のため自動採点が難しく、模範解答との類似度判定や複数観点(心情転換の妥当性/字数/文脈整合)によるルーブリック評価が必要。
