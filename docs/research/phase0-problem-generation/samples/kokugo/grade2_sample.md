# 国語 2年生サンプル問題セット(領域: 漢字・句読点・読解)

生成条件: `kokugo-prompt.md` のテンプレートに grade=2, domain=漢字の読み書き・句読点・読解(段落) を適用して生成。

---

### 問題1(基礎)
つぎの かんじの よみかたを ひらがなで かきましょう。
「brackets省略: 「時間」「друг省略」」
「時間」「毎日」「妹」

- 解答: じかん / まいにち / いもうと
- 解説: いずれも2年生までの学年別漢字配当表に含まれる漢字。
- 対応項目: 〔知識及び技能〕(1)エ 漢字の読み

### 問題2(標準)
つぎの文に、「、」(読点)を1つ入れて、読みやすい文に直しましょう。

「きのう学校へ行って友達と遊んで楽しかったです。」

- 解答例: 「きのう、学校へ行って友達と遊んで楽しかったです。」
- 解説: 文の切れ目や意味の区切りに読点を打つことで、読みやすさが変わることを体感させる問題。
- 対応項目: 〔知識及び技能〕(1)ウ 句読点の打ち方

### 問題3(標準・読解)
つぎの文章を読んで、あとの問いに答えましょう。

「たけしは、朝ごはんを食べたあと、忘れ物がないかランドセルの中を確かめました。
それから、げんきよく『行ってきます』と言って家を出ました。」

問: たけしが家を出る前に した ことを、じゅんばんに 2つ 書きましょう。

- 解答: ①朝ごはんを食べた ②ランドセルの中の忘れ物を確かめた
- 解説: 段落内の出来事を時間の順序に沿って正しく並べて読み取る問題。
- 対応項目: C(1) 構造と内容の把握(時間的順序・事柄の順序を捉える)

### 問題4(応用)
問題3の文章を読んで、「たけしが忘れ物を確かめたのは なぜだと 思いますか」を、
自分の考えを 1文で 書きましょう。

- 解答例: 「忘れ物をすると学校でこまるから、確かめたのだと思います。」
- 解説: 本文に直接書かれていない「理由」を、書かれた事実(忘れ物がないか確かめた)から推測して
  自分の言葉で表現させる応用問題。
- 対応項目: C(1) 精査・解釈(叙述を基に理由を考える)/B(1) 書くこと
- 難易度メモ: 正答が一つに定まらない推測・記述問題のため、「本文の内容と矛盾しない理由になっているか」を
  評価観点とするルーブリックが必要。
