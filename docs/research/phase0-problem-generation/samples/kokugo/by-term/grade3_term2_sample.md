# 国語 3年生 2学期サンプル問題セット(9〜12月ごろ)

生成条件: `term-prompt.md` に grade=3, subject=国語, term=2学期 を適用して生成。
対象単元: 物語文(場面の移り変わり)、説明文(比較・分類)、秋配当の漢字

---

### 問題1(物語文・場面の移り変わり・学期前半)
次の文章を読んで、あとの問いに答えましょう。

「はじめ、きつねは森の中でひとりぼっちで暮らしていた。ある日、けがをしたうさぎに出会い、
手当てをしてあげた。それから、きつねとうさぎは仲良く暮らすようになった。」

問: この物語で、きつねの様子はどのように変わりましたか。「はじめは〜、それから〜」の形で書きましょう。

- 解答例: 「はじめはひとりぼっちだったが、それからうさぎと仲良く暮らすようになった。」
- 解説: 場面の移り変わりに注目し、登場人物の様子の変化を整理して読み取る力を問う。
  1学期の「事実を時系列で読み取る」から一歩進み、心情・状況の変化を捉える設問にした。
- 対応単元: 物語文(場面の移り変わり)/学期の目安: 前半〜中盤(9〜10月ごろ)
- 対応項目: C(1) 精査・解釈(場面の移り変わりと登場人物の変化)

### 問題2(説明文・比較分類・学期中盤〜後半)
次の文章を読んで、あとの問いに答えましょう。

「たんぽぽの綿毛は風に乗って遠くまで飛ぶ。一方、どんぐりは重いので、ころがって移動する。」

問: この文章は、たんぽぽとどんぐりの何を比べていますか。

- 解答: 種(たね)の飛び方・移動の仕方
- 解説: 「一方」という比較を表す言葉に注目し、2つの物事を比べて説明する文章構成を読み取らせる。
- 対応単元: 説明文(比較・分類)/学期の目安: 中盤〜後半(11月ごろ)
- 対応項目: C(1) 構造と内容の把握(比較・分類の文章構成)

### 問題3(漢字・学期を通して)
次の漢字の読み方をひらがなで書きましょう。
「感想」「予想」「向こう」

- 解答: かんそう / よそう / むこう
- 解説: 3年生2学期(9〜12月)に配当される漢字の一部。
- 対応単元: 漢字(2学期配当分)/学期の目安: 通して
- 対応項目: 〔知識及び技能〕(1)エ 漢字の読み

## 評価コメント
- 1学期の「観察記録文(事実を時系列で書く)」から、2学期の「比較・分類の説明文」へと
  説明的文章の構成の複雑さが段階的に上がっており、学期をまたいだ難易度の連続性が確認できた。
- 物語文の読解も「場面の移り変わり」という2学期特有の観点が明確に反映され、
  1学期には登場しなかった「心情・状況の変化」を問う設問が自然に生成された。

※比較・分類の説明文を扱う時期は教科書会社によって10月〜1月と幅がある。
