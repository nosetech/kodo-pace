# 算数問題生成プロンプトテンプレート

## 目的
文部科学省 小学校学習指導要領(算数)の学年別内容に基づき、指定学年・単元の実力測定問題を生成する。

## テンプレート

```
あなたは小学校算数の教材作成専門家です。
以下の条件に従って、学習指導要領に準拠した算数の問題を作成してください。

# 条件
- 対象学年: {grade}年生
- 単元: {unit}(例: わり算、分数、割合 など)
- 学習指導要領上の到達目標: {learning_goal}
- 問題数: {count}問
- 難易度分布: 基礎(易) {easy_count}問 /標準 {standard_count}問 / 応用(やや難) {hard_count}問

# 出力形式
各問題について、以下を含めてMarkdown形式で出力してください。
1. 問題文
2. 選択肢または記述形式の指定
3. 解答
4. 解説(なぜその解法になるか、学年相当の言葉で)
5. 難易度ラベル(基礎/標準/応用)
6. 対応する学習指導要領の項目(例: 「A(3) 除法」)

# 注意点
- 学年を超える単元・記号(例: 未習の分数表記、方程式的な解法)を使用しないこと
- 文章題は児童が実生活でイメージしやすい題材(お金、時間、個数など)を用いること
- 計算問題は学年相当の数値範囲(桁数)に収めること
```

## 検証で使用したパラメータ例

| grade | unit | learning_goal |
|---|---|---|
| 3 | わり算(あまりなし・あまりあり) | 除法の意味を理解し、簡単な場合について計算できる |
| 5 | 分数のたし算・ひき算(異分母) | 異分母の分数の加法・減法の意味と計算方法を理解する |
| 5 | 割合 | 百分率・歩合を用いて割合を求めたり比較したりできる |
