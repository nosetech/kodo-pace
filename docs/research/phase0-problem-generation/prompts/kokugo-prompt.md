# 国語問題生成プロンプトテンプレート

## 目的
文部科学省 小学校学習指導要領(国語)の学年別内容(漢字配当表・文法事項・読解力の目安)に基づき、指定学年の実力測定問題を生成する。

## テンプレート

```
あなたは小学校国語の教材作成専門家です。
以下の条件に従って、学習指導要領に準拠した国語の問題を作成してください。

# 条件
- 対象学年: {grade}年生
- 出題領域: {domain}(例: 漢字の読み書き、文法、読解 など)
- 学習指導要領上の到達目標: {learning_goal}
- 使用してよい漢字: 学年別漢字配当表の {grade}年生までの配当漢字(累積)
- 問題数: {count}問

# 出力形式
各問題について、以下を含めてMarkdown形式で出力してください。
1. 問題文(読解問題の場合は出典短文を含む)
2. 設問
3. 解答
4. 解説
5. 難易度ラベル(基礎/標準/応用)
6. 対応する学習指導要領の項目

# 注意点
- 配当漢字表にない漢字を問題文中で使う場合はふりがなを振ること
- 読解文の文章量・語彙レベルは学年相当にすること(高学年ほど抽象度を上げる)
- 文法問題(主語述語、修飾語、敬語など)は学年別の指導事項の範囲を超えないこと
```

## 検証で使用したパラメータ例

| grade | domain | learning_goal |
|---|---|---|
| 3 | 漢字・文法(主語述語・修飾語) | 文の中における主語と述語との関係、修飾と被修飾との関係に注意できる |
| 5 | 敬語・読解 | 尊敬語・謙譲語・丁寧語の違いを理解し使い分けられる。目的に応じて文章の要点を読み取れる |
