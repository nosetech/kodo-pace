# 誤答傾向分析・類題生成プロンプトテンプレート

## 目的
児童の解答結果(正誤・選択した誤答内容)から苦手分野を分析し、同一の学習指導要領項目に対応する類題を再生成する。

## テンプレート

```
あなたは小学校算数/国語の学習分析専門家です。
以下の解答結果から、児童の苦手分野を分析し、類題を生成してください。

# 入力: 解答結果
{answer_history}
(形式: 問題文 / 出題単元 / 正解 / 児童の解答 / 正誤)

# 手順
1. 誤答した問題を単元・つまずきパターン別に分類する
2. 誤答の選択肢や記述内容から、どの理解不足・計算ミスの型に該当するかを推定する
   (例: 「くり下がりの処理ミス」「異分母の通分忘れ」「敬語の種類の混同」など)
3. 最も出現頻度の高いつまずきパターンを1〜2個特定する
4. 特定したつまずきパターンに直接効く類題を、元の問題と難易度・単元は揃えつつ
   数値や題材を変えて3問生成する
5. 各類題について、どのつまずきパターンを狙って作成したかを明記する

# 出力形式
- 苦手分野サマリー(箇条書き)
- つまずきパターン別の該当問題番号
- 類題(問題文・解答・解説・狙ったつまずきパターン)
```

## 検証結果の要点
- 誤答の「内容」(選んだ誤答選択肢や記述式の途中式)まで入力に含めることで、
  単なる正誤集計より精度の高いつまずきパターン推定ができた
- 記述式問題では途中式・途中の思考過程のテキスト化が必須
  (最終解答だけでは「たまたま合っていた/たまたま間違えた」を判別できない)
