# 学期(時期)対応プロンプトテンプレート

## 目的
同じ学年でも1学期・2学期・3学期で学習している単元は異なるため、
「今この時期に学校で習っている内容」に沿った問題を生成できるかを検証する。

## 前提となる課題
文部科学省 学習指導要領は**学年ごとの到達目標**を定めているが、
「どの単元を何月に教えるか」は指導要領には明記されておらず、
**教科書会社ごとの年間指導計画(年間指導計画表)**によって決まる。
そのため、学期対応の問題生成は「学習指導要領の知識」だけでなく
「一般的な年間指導計画の知識(教科書会社によらない標準的な順序)」を
別途プロンプトに組み込む必要がある。

## テンプレート

```
あなたは小学校{subject}の教材作成専門家です。
以下の条件に従って、対象の学期に学校で学習している内容に沿った問題を作成してください。

# 条件
- 対象学年: {grade}年生
- 対象学期: {term}(1学期 / 2学期 / 3学期)
- 学期の目安期間: {term}が 4〜7月(1学期)/ 9〜12月(2学期)/ 1〜3月(3学期) であることを踏まえること
- 参照する年間指導計画: {curriculum_plan}
  (指定がない場合は、主要教科書会社(東京書籍・啓林館・光村図書等)で
   共通して見られる一般的な単元順序を採用し、その旨を出力に明記すること)
- 問題数: {count}問

# 出力形式
各問題について、以下を含めてMarkdown形式で出力してください。
1. 問題文
2. 解答・解説
3. 対応する単元名
4. その単元が学期のどのあたり(前半/中盤/後半)で扱われる内容かの目安
5. 対応する学習指導要領の項目

# 注意点
- 前の学期までに習っていない単元・解法を使わないこと(例: 2学期の問題で3学期に習う内容を使わない)
- 教科書会社によって単元順序が前後する場合があることを、出力の末尾に注記すること
```

## 検証で使用したパラメータ例

| grade | subject | term | 対象単元(一般的な年間指導計画の例) |
|---|---|---|---|
| 3 | 算数 | 1学期 | かけ算の筆算、時刻と時間、わり算(あまりなし)、大きい数 |
| 3 | 算数 | 2学期 | わり算(あまりあり)、円と球、小数、重さ、分数 |
| 3 | 算数 | 3学期 | □を使った式、そろばん、二等辺三角形・正三角形、表とグラフ |
| 3 | 国語 | 1学期 | 詩の音読、説明文(観察記録)、ローマ字 |
| 3 | 国語 | 2学期 | 物語文(場面の移り変わり)、説明文(比較・分類) |
| 3 | 国語 | 3学期 | 物語文の山場の読み取り、意見文・報告文、1年間のまとめ |
